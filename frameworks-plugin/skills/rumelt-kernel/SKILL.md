# The Rumelt Kernel

> Real strategy is a kernel: an honest diagnosis, a guiding policy, and coherent actions that reinforce each other.

**Author:** Richard Rumelt, UCLA Anderson School of Management
**Source:** *Good Strategy Bad Strategy: The Difference and Why It Matters* (Crown Business, 2011)
**Field-tested:** Apple's turnaround under Jobs, Schwarzkopf's Gulf War left-hook maneuver, Walmart's early competitive positioning

## When to use this
- You have goals and vision but no actual strategy
- A plan feels like a list of disconnected initiatives
- You suspect you're avoiding a hard choice ("bad strategy")
- You need to pressure-test a strategy before committing resources
- Leadership is confusing aspirations with a path to achieve them

## The framework
- **Diagnosis** — What is actually going on? The root-cause assessment, not goals or vision. "If you can't find the diagnosis, the rest of the document is built on sand."
- **Guiding Policy** — A high-level approach that channels action; a direction that constrains and focuses decisions, not a detailed plan.
- **Coherent Actions** — Coordinated steps that reinforce each other and carry out the guiding policy. Incoherent actions cancel each other out.

## How to run it (step by step)
1. Describe the situation in one paragraph.
2. Ask: *What is the true constraint or challenge?* (not a symptom)
3. Formulate a guiding policy: a principle, not a list of tasks.
4. Enumerate only actions that reinforce each other.

## Facilitating with the user
When this skill activates, you (Claude) should:
1. Restate or gather the user's context (the situation, the challenge, available resources/constraints)
2. Walk through Diagnosis → Guiding Policy → Coherent Actions sequentially, applied to their situation
3. Make any filled-in gaps explicit and labeled as assumptions
4. Flag the step where the analysis is weakest or you lack data (usually the diagnosis)
5. Suggest 1-2 complementary frameworks for a second pass (First Principles, MECE Issue Tree)

## Output template
**Diagnosis:** <root challenge in 2-3 sentences>
**Guiding Policy:** <single directional principle>
**Coherent Actions:**
- <action 1 — how it reinforces the others>
- <action 2 — how it reinforces the others>
- <action 3 — how it reinforces the others>
**Uncertainties:** <where the diagnosis is unproven>

## Watch out for
- Confusing goals or vision with diagnosis
- Bad strategy as active avoidance of hard choices
- Listing actions that individually look good but cancel each other out
- A guiding policy that is actually a task list in disguise
