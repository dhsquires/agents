# SPIN Selling (Situation → Problem → Implication → Need-Payoff)

> Sell by asking the right sequence of questions so the buyer articulates their own need — not by pitching.

**Author:** Neil Rackham, Huthwaite Research Group
**Source:** *SPIN Selling* (McGraw-Hill, 1988); based on analysis of 35,000+ sales calls across 23 countries over 12 years
**Field-tested:** IBM, Xerox, and every major B2B enterprise sales organization; still the only sales framework built from observed field data rather than opinion

## When to use this
- Preparing for a complex or high-value B2B sales call
- Running a discovery or qualification conversation
- A deal stalls because the buyer doesn't feel the urgency to change
- Coaching a sales rep on questioning technique
- Structuring questions instead of feature-dumping

## The framework
- **Situation** — Gather facts about the buyer's current state (use sparingly; too many feel like an interrogation)
- **Problem** — Identify pain points, difficulties, and dissatisfactions with the current situation
- **Implication** — Ask questions that help the buyer articulate the downstream consequences of the problem (most powerful and most underused step)
- **Need-Payoff** — Ask questions that get the buyer to articulate, in their own words, the value of solving the problem

## How to run it (step by step)
1. Limit Situation questions — do your homework first
2. Spend most time on Implication questions: "If this problem continues, what happens to...?"
3. Never close before the buyer has stated their own Need-Payoff
4. Tie your solution to *their exact words* from Need-Payoff

## Facilitating with the user
When this skill activates, you (Claude) should:
1. Restate or gather the user's context (product/service, prospect role/company, what's known from research)
2. Walk through each SPIN stage sequentially, applied to their deal
3. Make any filled-in gaps explicit and labeled as assumptions
4. Flag the step where the analysis is weakest or you lack data
5. Suggest 1-2 complementary frameworks for a second pass

## Output template
- **Opening:** brief framing of the call
- **Situation questions (1-2):** assuming research is done
- **Problem questions (3-4):** surface likely pain points
- **Implication questions (2-3):** amplify consequences
- **Need-Payoff questions (1-2):** let the buyer articulate value
- **Solution tie-in:** map your offering to the buyer's own words

## Watch out for
- Over-asking Situation questions — it feels like an interrogation
- Skipping Implication, the highest-impact step
- Closing before the buyer voices their own Need-Payoff
- Pitching features instead of letting the buyer surface value
