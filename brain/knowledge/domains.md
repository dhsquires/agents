# Knowledge Domains

> _A map of what this person knows and how deeply, so an agent can calibrate explanations (skip basics in deep areas, scaffold in shallow ones). Updated as the stack changes._

## Depth scale

- **1 — Aware:** knows it exists, can follow a conversation.
- **2 — Working:** can use it with reference material.
- **3 — Fluent:** uses it independently and confidently.
- **4 — Expert:** teaches it, handles edge cases, has strong opinions.
- **5 — World-class:** pushes the frontier of the domain.
