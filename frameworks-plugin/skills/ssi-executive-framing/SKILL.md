# Situation → Solution → Impact (SSI)

> Frame an executive conversation by establishing shared context, stating one clear recommendation, and quantifying the impact.

**Author:** DoubleDigit Sales / executive coaching lineage (popularized in enterprise sales and consulting training)
**Source:** "How to Frame-Up an Executive Conversation" (LinkedIn article by sales training practitioners)
**Field-tested:** Standard in enterprise sales enablement

## When to use this
- Pitching a recommendation to a C-suite or VP audience
- Framing an enterprise sales conversation
- You tend to lead with your solution before context lands
- You need a crisp, decision-ready ask
- Quantifying the value of a proposal for leadership

## The framework
- **Situation** — Establish shared context and the current state the executive recognizes.
- **Solution** — Your recommendation, clearly stated.
- **Impact / Next Steps** — The measurable benefit and what happens next.

## How to run it (step by step)
1. Never open with your solution — establish shared context first.
2. Keep the Situation to 2–3 sentences (what they already know).
3. State the Solution as a single declarative recommendation.
4. Quantify the Impact (time, money, risk reduction).

## Facilitating with the user
When this skill activates, you (Claude) should:
1. Restate or gather the user's context (topic, audience level, the recommendation, measurable benefits)
2. Walk through Situation → Solution → Impact sequentially, applied to their situation
3. Make any filled-in gaps explicit and labeled as assumptions
4. Flag the step where the analysis is weakest or you lack data (usually the quantified impact)
5. Suggest 1-2 complementary frameworks for a second pass (SCQA Pyramid, SCR)

## Output template
**Situation:** <2-3 sentences of shared context>
**Solution:** <single declarative recommendation>
**Impact / Next Steps:** <quantified benefit (time/money/risk) + the next action>
*Audience tuned for:* <C-suite | VP | Director>

## Watch out for
- Opening with the solution before context is shared
- A Situation that introduces new or controversial claims
- Vague impact ("it'll help") instead of quantified value
- More than one recommendation buried in the Solution
- Forgetting the explicit next step
