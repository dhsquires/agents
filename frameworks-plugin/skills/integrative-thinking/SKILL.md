# Integrative Thinking (Salience → Causality → Architecture → Resolution)

> Don't choose between two opposing options — synthesize a third that captures the best of both.

**Author:** Roger Martin, former Dean, Rotman School of Management (University of Toronto)
**Source:** *The Opposable Mind: How Successful Leaders Win Through Integrative Thinking* (Harvard Business Review Press, 2007)
**Field-tested:** Multi-year study of 50+ successful leaders including A.G. Lafley (P&G), Bob Young (Red Hat), Isadore Sharp (Four Seasons)

## When to use this
- Facing an either/or choice where both options have downsides
- Suspecting a false dichotomy or forced trade-off
- Two strong factions advocating opposing strategies
- Wanting a creative synthesis rather than a compromise
- Resolving tension between competing models or values

## The framework
When facing an either/or choice, integrative thinkers refuse to choose. Instead they:
1. **Salience** — Identify features of the problem beyond the obviously relevant ones
2. **Causality** — Consider multi-directional, non-linear causal relationships, not just linear ones
3. **Architecture** — Keep the whole problem in mind while working on each part; see how pieces connect
4. **Resolution** — Generate a creative solution superior to both original options, containing elements of each

## How to run it (step by step)
1. State the two seemingly opposed models or options
2. List all salient features of both — including non-obvious ones
3. Map the causal relationships between features across both models
4. Hold the tension: "What solution would be superior to both?"
5. Synthesize a third option

## Facilitating with the user
When this skill activates, you (Claude) should:
1. Restate or gather the user's context (Option A vs Option B and why each is attractive)
2. Walk through salience, causality, architecture, and resolution sequentially
3. Make any filled-in gaps explicit and labeled as assumptions
4. Flag the step where the analysis is weakest or you lack data
5. Suggest 1-2 complementary frameworks for a second pass

## Output template
- **The dilemma:** Option A vs Option B
- **Salient features:** what makes each attractive, including non-obvious factors
- **Causal map:** how features relate across both models
- **Synthesis (resolution):** a third model with the best elements of each and the downsides removed
- **Reasoning:** how the synthesis resolves the tension

## Watch out for
- Defaulting to compromise (split the difference) instead of true synthesis
- Considering only the obvious salient features
- Assuming linear causality when relationships are multi-directional
- Losing the whole while optimizing one part
